# Aranghata Satadal Club (আড়ংঘাটা শতদল ক্লাব)
Official website and digital portal for **Shree Shree Shyama (Kali) Puja 2026** at Aranghata, Nadia, West Bengal.

🌐 **Domain**: [aranghatasatadalclub.com](https://aranghatasatadalclub.com)

---

## 🌺 Overview

Aranghata Satadal Club, established in the Ranaghat subdivision of Nadia district, celebrates over **57+ years** of rich cultural heritage, spiritual devotion, and community service. Welcoming over **2 Lakh+ devotees** annually, this responsive web portal showcases:

- **Live Countdown Timer**: Real-time counter to Maha Amavasya Kali Puja 2026.
- **Pandal & Pratima Theme**: Highlighting the 2026 *Bishnupur Terracotta Sanctuary* theme, traditional Daker Saaj idol artistry, and Chandannagar dynamic illumination.
- **Puja & Event Schedule**: Interactive day-by-day timetable (Inauguration, Amavasya Puja, Bhog distribution, Cultural & Drama evenings, Blood Donation Camp, and Bisorjon Carnival).
- **Interactive Lightbox Gallery**: Curated visual glimpses of mandap architecture, idol, and social seva.
- **Location & Visitor Guide**: Transit routes via Aranghata Railway Station (Sealdah-Gede line), bus routes, parking advisory, and OpenStreetMap integration.
- **Donation & Seva Support**: UPI QR Code and instant copy functionality (`satadalclub@upi`) for voluntary festival & community seva contributions.
- **Festive Dhak Ambience**: Interactive Web Audio API sound generator synthesizing Bengal Kali Puja Dhak rhythms without external audio dependencies.

## 🛠️ Tech Stack

- **HTML5** & Semantic Markup
- **Tailwind CSS** (via CDN with custom palette & glow utilities)
- **Vanilla JavaScript** (Countdown timer, schedule tabs, lightbox, Web Audio synth, floating canvas particles)
- **Lucide Icons**
- **Google Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit), [Cinzel](https://fonts.google.com/specimen/Cinzel), and [Hind Siliguri](https://fonts.google.com/specimen/Hind+Siliguri) (Bengali)

## 🚀 Getting Started

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/Souyash/aranghatasatadalclub.git
cd aranghatasatadalclub
open index.html
```

Or run a local static server:

```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
